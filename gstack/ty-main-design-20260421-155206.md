## Problem Statement

No good place for AI-powered web and mobile app builders to sell. Existing directories (Product Hunt, Futurepedia) are SEO dumps with no quality gate. What's missing: a focused marketplace where builders list apps with prices, AI scores them by quality and taste, and buyers contact sellers directly — no platform payment processing, no friction.

## What Makes This Cool

The scoring engine IS the product. Every listing has a publicly visible AI quality score with per-dimension breakdown and critique. Builders submit to learn from the critique, not just to get listed. The score badge is the viral mechanic — "my app scored 84/100" is shareable.

## Shipped: Core Flows

**Creator flow:**
1. Sign up (email + password — GitHub/Google OAuth available if enabled in Supabase dashboard)
2. Submit listing: platform (Web / iOS / Android / Cross-platform), app name, URL/store link, description, category, price, optional screenshot
3. Optional: fill Pitch & Due Diligence — hook (140 chars), AI secret sauce, MAU/MRR, tech stack tags, monthly burn, maintenance level, assets included, freeform notes
4. Gemini 2.5 Flash evaluates: takes screenshot via microlink.io, scores across 5 dimensions, returns score 0-100 + critique
5. Listing goes live with score badge. Owner can edit or delete from detail page.

**Buyer flow:**
1. Browse feed (sorted by AI score, filter by category/price/platform)
2. Click listing → new page with full details, screenshot, AI critique (TL;DR default, expandable), pitch & DD section
3. "Send inquiry" → encrypted email relay. No login required. One relay per buyer+listing. 24h TTL.

**Listing states:**
- `pending` → "Scoring…" badge. Visible immediately after submit.
- `scored` → Score badge (0-100), breakdown bars, critique with highlighted key sentence
- `scoring_failed` → "Scoring failed" UI, re-score planned for V2
- `auth_required` screenshot → manual upload prompt shown to owner

## Shipped: Tech Stack

- **Frontend:** Next.js 14 App Router, TypeScript, system monospace font, custom CSS variables (BAUD-inspired aesthetic: cream bg, ink borders, flat offset shadows, neon yellow-green accent)
- **Backend:** Supabase (Postgres + Auth + Storage + Realtime)
- **AI Scoring:** Gemini 2.5 Flash via `@google/generative-ai` — runs server-side in Next.js API route, no Fly.io worker needed
- **Screenshot capture:** microlink.io (free, no key) → Supabase Storage `screenshots/` bucket
- **Email relay:** Resend (configured but API key needed for production sends)
- **Encryption:** AES-256-GCM for creator emails + buyer emails at rest

## Shipped: Scoring Rubric

| Dimension | Weight | 0-3 | 4-6 | 7-10 |
|---|---|---|---|---|
| Problem clarity | 25% | Vague or me-too | Specific, fuzzy audience | Nails who suffers and why |
| UX quality | 25% | Can't figure out in 30s | Understandable but clunky | Clear in 10s, zero friction |
| AI integration | 20% | AI is cosmetic | AI does real work, replaceable | AI is the core differentiator |
| Polish | 15% | Broken states, typos | Works but unfinished | Feels shipped with pride |
| Novelty | 15% | Duplicate product | Unique angle on known problem | New framing nobody solved |

Score = weighted average × 10 (0–100). Mobile listings evaluated against mobile UX conventions.

## Shipped: Security

- HMAC-SHA256 on score callback (5-minute replay window)
- `EMAIL_ENCRYPTION_KEY`: AES-256-GCM, NEVER rotate without migration
- `INTERNAL_SECRET`: protects `/api/capture-screenshot` and `/api/score-listing` from external calls
- Rate limit: 3 listings / 7 days per account. `ADMIN_EMAILS` env var bypasses.
- Row-Level Security on all Supabase tables

## Shipped: UI Features

- Feed: category filters, sort (AI Score / Newest / Price), breakdown toggle, grid/list layout
- Listing cards: score badge (color-coded), mini dimension bars, platform badge for mobile
- Listing detail: TL;DR critique (expandable), highlighted key sentence, Pitch & DD section, owner edit/delete
- Submit flow: 3 steps (App details → Pricing → Pitch & Info) + success. Actual API call on step 3.
- Nav: username dropdown with Change display name + Sign out
- How It Works page at /how-it-works with scoring rubric and FAQ
