## Scoring Engine

- **Model:** Gemini 2.5 Flash (via `@google/generative-ai`)
- **Screenshot:** microlink.io → Supabase Storage (`screenshots/auto/{id}.jpg`)
- **Rubric:** 5 dimensions × weights: problem_clarity 25%, ux_quality 25%, ai_integration 20%, polish 15%, novelty 15%
- **Score:** weighted average × 10 = 0–100
- **Platform-aware:** mobile platform flag adjusts UX evaluation criteria
- **Failure handling:** malformed JSON → `status: scoring_failed`, logged, not silent

## Key Interactions to Verify

- Submit listing → 201 with `status: pending` → Gemini scores in background → Realtime pushes badge update
- Score callback with wrong HMAC → 401, listing unchanged
- Contact seller → relay email forwarded once → duplicate contact → 200 "already sent"
- Relay token past `expires_at` → 410 Gone
- Rate limit: 4th submission in 7 days → 429 with message (admin emails bypass)
- No screenshot uploaded → microlink.io auto-capture fires in background
- Auth-required URL → `screenshot_status: auth_required` → manual upload prompt shown
- Owner visits own listing → Edit / Delete shown instead of contact form
- Delete listing → confirm modal → deleted → redirect to feed
- Change display name → updates profiles table + all listing creator_name fields

## Edge Cases

- Gemini malformed JSON → `status: scoring_failed`, listing shows "Scoring failed" UI
- microlink.io timeout → screenshot skipped, scoring from description only
- `EMAIL_ENCRYPTION_KEY` rotated → decryption throws specific error, `forward_status: failed`, not silent
- Supabase Realtime WebSocket down → feed still works, scores don't update live (acceptable)
- `GOOGLE_AI_API_KEY` missing → 503 from score-listing route, listing stays pending
