## Affected Pages/Routes

- `POST /api/listings` — listing submission with rate limiting and validation
- `PATCH /api/listings/{id}/score` — callback from Fly.io worker to update score (must validate shared secret)
- `POST /api/contact` — relay contact form (idempotent per buyer+listing)
- `GET /feed` — public listing feed (sort by score, filter by category/price)
- `GET /listings/{id}` — listing detail page (score badge, screenshot, critique, contact form)

## Key Interactions to Verify

- Submit listing → immediately returns 201 with `status: pending`, listing appears in feed with "Scoring..." badge
- Score callback arrives → listing updates in real-time via Supabase Realtime (no page refresh needed)
- Contact seller → relay email arrives in seller inbox with buyer email + message + listing price
- Second contact from same buyer on same listing → returns 200 "Your message was already sent" (no duplicate email)
- Submit 4th listing in a week → returns 429 with clear rate limit message
- Auth-required URL submitted → screenshot_status set to auth_required, listing shows manual upload prompt

## Edge Cases

- Playwright timeout (10s): listing created with `screenshot_status: failed`, GPT-4o scores from description only
- GPT-4o returns malformed JSON: worker logs error, listing stays `status: pending`, not silently lost
- Scoring callback with wrong shared secret: returns 401, listing unchanged
- Relay token past `expires_at`: return 410 Gone (or 404) — do not forward
- Feed with zero listings: empty state UI shown, not broken page
- Feed with listings in `pending` state: "Scoring..." badge shown, no score column
- Relay `EMAIL_ENCRYPTION_KEY` changed: decryption throws, worker logs specific error (not silent fail)

## Critical Paths

- Creator submits app URL → scores appear within 5 minutes → score badge is public/shareable
- Buyer contacts seller → seller receives email with buyer's email address so they can reply directly
- Rate limit enforced: account cannot submit more than 3 listings in 7 days
- Scoring callback authenticated: only the Fly.io worker (with shared secret) can write scores back

## E2E Tests Recommended

1. Full creator flow: sign up → submit URL → wait for pending → score arrives → share URL
2. Full buyer flow: browse feed → click listing → fill contact form → verify relay email received
3. Relay idempotency: same buyer submits contact form twice → only one email arrives at seller inbox
